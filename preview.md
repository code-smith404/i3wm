# Preview

Catppuccin Mocha theme with rounded corners, blur, and gaps.

Layout: top Polybar with workspaces, window title, date, audio, memory, CPU, network, battery. Notifications via Dunst (top-right). App launcher via Rofi.

Keybindings:
- Mod+Return: terminal (Alacritty)
- Mod+d: Rofi drun
- Mod+1..0: workspaces
- Mod+Shift+q: kill
- Mod+f: fullscreen
- Mod+r: resize mode
- Mod+Shift+e: exit

Visuals: 12px inner gaps, 6px outer, 2px mauve borders, 10px corner radius, dual-kawase blur, soft shadows.
